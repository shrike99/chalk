# Changelog

## 2.0.0

- **Your own tests first.** Hidden edge-case hints wait until you've written tests of your own; Chalk
  shows which edge cases you anticipated and checks your expected answers against the reference.
- **Code walkthrough** for Python: step through your code line by line, with every variable drawn.
- **Edit and resend, regenerate**, and a **stop** button (or Esc) for a message Claude is still answering.
- **Interrupt by talking** while Claude speaks.
- **Small jobs on Haiku**: fresh-note summaries and complexity explanations.
- Lighter conversations: Chalk ignores your Claude Code setup, sends long format instructions only
  when needed, and shows where each note's tokens go.
- Resizable test-results pane.

## 1.x

- Coding exercises in Python, JavaScript, Java, C and SQL, with one-click compiler downloads.
- "How fast is it?": predict your solution's complexity, then measure it.
- Practice papers that follow the format of past papers you attach, with drawn figures, edits one
  question at a time, a print-ready viewer and PDF export.
- File uploads (PDFs and images), Predict-then-check, a context meter, and "continue in a fresh note".
- The animated canvas, voice (Whisper and Kokoro), notes, modes and the desktop app.
